# Z-Score Line Chart

Интерактивный график на React с использованием библиотеки Recharts, который показывает данные и подсвечивает точки, где модуль z-score превышает 1.

## Особенности

- Визуализация данных с помощью линейного графика
- Автоматический расчет z-score для каждой точки
- Подсветка точек с аномальными значениями (|z-score| > 1)
- Интерактивные подсказки при наведении
- Адаптивный дизайн

## Установка

1. Клонируйте репозиторий:
```bash
git clone [URL вашего репозитория]
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите проект:
```bash
npm start
```

## Технологии

- React
- TypeScript
- Recharts
